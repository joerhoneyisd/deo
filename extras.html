Component

Stat Band

A full-bleed, high-contrast section for headline numbers — program results, counts, dollar amounts. No imagery; the numbers are the visual. Each number counts up from 0 when it scrolls into view (about 3 seconds, eased), and respects "reduce motion" settings by jumping straight to the final value. Works with any number of stats — the grid reflows from 2 columns on mobile up to 5 on desktop.

Tabs

An accessible tablist for switching between two or more audiences or views on one page (for example, “For Employers” and “For Youth”). Panels are hardcoded in the HTML; the script only toggles which one is visible. Supports arrow keys, Home/End, and deep links such as page.html#tab-youth. Put it on a .tint section or a white one; .tp-lead takes an optional .ph photo (drop the photo and add .solo).

First panel

Panel content goes here. Use .tp-lead for a lead block and .tp-cols for a two-column row beneath it.

Second panel

Only one panel is visible at a time. Arrow keys, Home, and End move between tabs.

System

Program page section system

Every program or detail page is assembled from the same frame and a shared catalog of section types. Pick sections by what the program has, not by a fixed template.

  • Page types. Single program (what it is, who qualifies, how to apply, results) and sector initiative (overview, reports, results; no eligibility or application). The umbrella hub is designed separately.
  • Tab vocabulary (fixed). Overview, Eligibility, How to Apply, Results, FAQs & Resources. No other labels.
  • Tab rules. A tab appears only if it has content. Overview is always first. A page with fewer than two non-empty tabs has no tab bar and shows its sections in one scroll.
  • Deep links. Each panel id is the tab’s anchor: #overview, #eligibility, #how-to-apply, #results, #faqs-resources. Any id inside a panel (such as #faq) opens its tab too.
  • Outside the tabs. Hero, glance bar, CTA, Downloads, Contact, Related programs.

Component

Dark section

Adds contrast between light sections, using the same treatment as the Home news section: gradient background, white type, light-blue secondary text, and hairline dividers. .dark uses the news gradient; .dark.alt mirrors it (as in the stat band) so two dark sections on a page do not look identical. Supported inside it: rules, events, downloads list, area chips, FAQ, contact cards, logo row, notes, and buttons (primary turns white). Guidelines: at most one dark section per tab panel, never two touching, and Contact is the standard dark section below the tabs. The footer is also dark, so keep Related programs (light) between them.
